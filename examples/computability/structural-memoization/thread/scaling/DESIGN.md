# A search whose size grows

The rules let up to five tiers pay. For k = 2 … 5 a source case in region k derives a plan and publishes it, and a target of the same signature reuses it. The planner extends every plan: the priority rule is only in the checker. The fresh search tests 4, 15, 64 and 325 complete plans; the plan criterion repeats it, so these counts are admitted. A reused plan costs one proof in the ontology and one in the criterion, whatever k is. [Design of the thread](../DESIGN.md)
